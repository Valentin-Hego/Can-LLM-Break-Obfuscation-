Arithmetic experiments

Obfuscator: Tigress
Technique: Flatten (check script for exact technique)
LLM: Gemini Pro + custom binary analysis pipeline

arithmetic_01_obf

Human recovered:
int f(int a, int b){
    return a+b;
}

int main(){
    printf(f(5,3));
    return 0;
}

Observation:
The obfuscator created 3 possible branches. All branches call f(), so checking f() makes recovery easy.

AI recovered:
int f(int a, int b) {
    return a + b;
}

int main() {
    int result = 0;

    for (int i=0;i<4;i++) {
        result = f(result,i);
    }

    printf("%d\n", result);
    return result;
}

Note:
The AI tried to infer missing information instead of fully recovering the program.

arithmetic_10_obf

Human recovered:
int f(int a,int b,int c){
    return b*b + a*c*-4;
}

int main(){
    printf(f(2,5,-3));
    return 0;
}

First AI result:
int f(int a,int b,int c){
    return b*b + a*c*-4;
}

int main(){
    return f(argc,argc,argc);
}

Observation:
Function logic was recovered but not the original parameters.

After more analysis:
int main(){
    printf("%d\n",f(2,5,-3));
    return 0;
}

Observation:
The AI often stops when the logic seems correct, even if the exact output is still wrong.
