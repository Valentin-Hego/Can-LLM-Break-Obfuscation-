loops_05_obf

AI recovered:
int f(int a,int b){
    int r=0;

    for(int i=0;i<b;i++){
        r=r+a;
    }

    return r;
}

int main(){
    int result=f(4,3);
    printf("%d\n",result);
    return 0;
}

Observation:
Recovery looks correct.
Function logic and parameters were recovered.
